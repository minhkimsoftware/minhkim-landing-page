# WarmLead Landing Page

Production-ready marketing site for an end-to-end **lead validation** automation service.

## Brand

- Primary color: `#003FF6`
- Product name: WarmLead
- Headline: Get consistent warm leads monthly
- Tagline: Lead validation system right on your phone! Grow your business today

## Stack

- HTML5 + CSS3 + Vanilla JavaScript
- No npm dependencies or build step
- Google Fonts: Sora + Source Sans 3

## Sections

1. Hero (brand, headline, dual CTAs, phone visual)
2. Stats
3. Features (5 core capabilities)
4. How it works
5. Services
6. Testimonials
7. Pricing tiers
8. FAQ
9. Contact / CTA form
10. Footer

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
# or: python -m http.server 8080
```

## Deploy

Push this repository to GitHub Pages, Netlify, Vercel, or any static host. Point the host at the repo root (`index.html`).

## Form

The contact form validates client-side and logs a demo payload to the console. Wire `script.js` submit handler to your lead API when ready.
